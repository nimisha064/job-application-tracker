# Job Application Tracker

A Flask-based web application for managing and tracking job applications.

## Features

- Add new job applications
- Edit existing applications
- Delete applications
- Track application status
- Set application priority
- Add follow-up dates
- Store job URLs and notes
- View application statistics on the dashboard

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
